# TabDisplay

Android タブレットを Windows PC のセカンドモニターにするソフト（PC 用）とアプリ（タブレット用）。

- USB でも Wi-Fi でもつながる（USB は PC の「接続する」を押すだけ、Wi-Fi は PC に出る QR コードを読むだけ）
- 遅れが少ない：グラボで撮って（Desktop Duplication）、グラボで圧縮（NVENC / AMF / Quick Sync / Media Foundation、なければ x264）し、タブレットは受け取ったらすぐ表示
- 1 秒に最大 60 枚
- タップ → クリック、長押し → 右クリック、なぞる → スクロール
- タブレットを回すと PC の画面も回る（設定で切り替え）
- 表示のしかた：PC と両方（広げる／同じ画面）、タブレットのみ、PC のみ
- Android 6 以上のタブレットで動く
- タブレットのアプリは PC から USB で直接入れられる
- 言語は既定でシステムの言語（日本語・英語）
- Windows の起動時に、右下のアイコンにしまった状態で開ける
- 2 本指タップで右クリック、つまむ・広げるで拡大縮小（Ctrl + ホイール）
- ペン対応：筆圧・傾き・サイドボタン・消しゴムつきで Windows のペンとして入る（Windows 10 1809 以降）
- タブレットの ⌨ ボタンでキーボード（日本語入力も）。つないだキーボードのキーもそのまま届く
- PC の音もタブレットで鳴らせる
- 仮想ディスプレイの拡大率（文字の大きさ）をタブレットに合わせて自動で設定
- タブレットを最大 4 台まで同時につなげる（それぞれ別の画面になる）
- 回線の混み具合に合わせて画質を自動で上げ下げ
- Wi-Fi：前につないだ PC を自動で見つけてつなぐ（PC の IP が変わっても大丈夫）

## 構成

```
android/   タブレット用アプリ（Kotlin、minSdk 23 = Android 6）
pc/        PC 用ソフト（C# / .NET 8 / Windows Forms）
.github/workflows/build.yml   ビルド（手で実行。APK と PC 用 zip とソース zip をリリースに置く）
```

## 仕組み

0. PC は UDP 38501 番に 2 秒ごとに「ここにいます」を出す（合言葉から作った ID だけ。合言葉そのものは出さない）
1. PC は TCP 38500 番で待つ。USB のときは `adb reverse tcp:38500 tcp:38500` で、タブレットの 127.0.0.1:38500 が PC につながる
2. タブレットは画面の大きさを送る → PC は仮想ディスプレイをその大きさで作る
3. PC は ffmpeg（ddagrab）でその画面を撮って H.264 にし、1 枚ずつ送る
4. タブレットは MediaCodec で Surface に直接描く（低遅延モード）
5. タッチは「画面の中の割合」で PC に送り、SendInput でマウス操作にする

仮想ディスプレイのオン／オフには管理者が要るので、「仮想ディスプレイを入れる」のときに
「最上位の特権で実行するタスク（TabDisplay Helper）」を作り、ふだんは確認なしでそれを呼ぶ。

## 初めて使うとき（PC）

1. `TabDisplay-win-x64.zip` を好きな場所に展開して `TabDisplay.exe` を開く
2. 「仮想ディスプレイを入れる」を押す（管理者の確認が 1 回出る）
3. タブレットの「USB デバッグ」をオンにして挿し、「接続する（USB）」を押す
   （アプリが入っていなければ自動で入る）
