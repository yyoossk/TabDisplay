# TabDisplay 更新履歴

## 次の更新（まだビルドしていない分）
- 色・文字の大きさを 1 か所にまとめた（PC は theme.json、タブレットは theme_colors.xml を変えるだけで見た目を変えられる）
- 設定の書き出し・読み込み（PC・タブレットとも）。PC を買い替えたときやタブレットを替えたときに移せる
- タブレットのアプリが落ちたとき、次につないだときに原因を PC に送るようにした（PC の「ログをまとめる」に入る）
- GitHub でビルドするたびに、つなぐ部分の自動テストを動かすようにした（PC: 合言葉・PIN・PING・ブラウザー用ページ、タブレット: 通信の形式など）

## build 5（2026-11-28）
- PC ソフトの窓をタブ（映す・入力と音と連携・つなぐと道具・そのほか）に分けて見やすくした
- 2 台以上のタブレットを横に並べて、1 つの大きな画面として使えるようにした
- タブレットの画面の向きを、TabDisplay だけ横・縦に固定できるようにした
- ほかのアプリを開いても、PC の画面を小窓で出し続けられるようにした（Android 8 以降）
- つないだキーボード：日本語キーボードの「半角/全角」「変換」「無変換」などのキーに対応。ゲーム向けに、記号も含めて全部キーで送るモードを足した
- 定型文：登録した文字を、タブレットの ☰ のメニューからタップで PC に入力できるようにした
- PIN：PC で決めると、タブレットは初めてつなぐときに PIN を聞くようにした（USB の「接続する」では自動で渡す）

## build 4（2026-11-28）
- PC ソフトとタブレットアプリで、更新履歴を見られるようにした（PC：窓の「更新履歴」・右下のアイコンのメニュー、タブレット：はじめの画面の「更新履歴」）
- ミニ画面（スマホ向け）：PC の画面の代わりに、時計・PC の通知・ショートカットのボタンを出す
- タブレットのカメラを PC の Web カメラにする（仮想カメラ「DirectShow Softcam」）
- タブレットのマイクの音を PC で使う（VB-CABLE を入れると PC のマイクとして使える）
- タッチを Windows のタッチとしてそのまま送る（2 本指の拡大・スワイプなどがそのまま効く）
- ランチャー：タブレットから PC のソフトを開く（既定はタスクバーにピン留めしたソフト）
- PC を使っていない間はタブレットの画面を消し、PC を使うと戻す（つないだまま）
- 左利き向けに、ボタンを左側に置けるようにした

## build 3（2026-11-28）
はじめての版。

### つなぐ
- USB（PC の「接続する」を押すだけ。アプリが入っていなければ PC から自動で入れる）
- Wi-Fi（PC に出る QR コードを読むだけ）。前につないだ PC は自動で見つけてつなぐ
- USB テザリング（USB デバッグなしでケーブル接続）
- ブラウザーで受ける（アプリなし。Chrome・Edge）
- PC なしで、タブレットの画面をほかのタブレットに映す
- タブレットは最大 4 台まで同時に
- 通信はすべて暗号化

### 映す
- 表示のしかた：PC と両方（広げる・同じ画面）・タブレットのみ・PC のみ・画面の一部（ウィンドウ・範囲）だけ
- タブレットの置き場所（PC の画面の右・左・上・下）
- タブレットを回すと PC の画面も回る
- 1 秒に最大 60 枚。グラボで撮ってグラボで圧縮（H.264・H.265）
- 画質の自動調整、画質の方針（自動・文字をくっきり・動きをなめらか）
- 省電力（画面が変わらないときは送らない・さわらないと暗くする）
- 文字の大きさ（拡大率）をタブレットに合わせる
- 画面を分ける（上に PC の画面、下にボタンとメモ）
- 拡大鏡、明るさ・暖色・コントラスト
- PC のロック解除・スリープ明けに自動で映し直す

### 操作
- タップでクリック、長押しで右クリック、なぞってスクロール
- 2 本指タップで右クリック、つまむ・広げるで拡大縮小
- ペン（筆圧・傾き・サイドボタン・消しゴム）、ペンタブレットモード
- タッチパッドモード
- キーボード（日本語入力も）、つないだキーボード
- ショートカットのボタン、左端の「右」「中」ボタンとスクロールの帯
- ゲームパッド（配置・大きさ・キーを変えられる）
- PC のショートカットキー（ウィンドウを次の画面へ・表示の切り替えなど。キーは自分で決められる）

### そのほか
- PC の音をタブレットで鳴らす
- クリップボード（文字）の共有、ファイルの受け渡し
- PC の通知をタブレットに出す
- 画面写真・録画
- 設定の組み合わせを名前で保存、つないだら決めたソフトを開く
- はじめの設定の案内、つながらないときの診断、ログをまとめる
- 自動更新、インストーラー
- 使用時間・通信量の記録
- 日本語・英語（既定はシステムの言語）
- Windows の起動時に、右下のアイコンにしまった状態で開ける

### ビルドで直した不具合
- ペン入力の部品の名前が Windows の描画用の名前とぶつかっていた
- 仮想ディスプレイではなく、音声用のドライバーを取り込んでいた
